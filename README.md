# CatCode Card Payments with EasyPay for WooCommerce

Accept card, Apple Pay and Google Pay payments in WooCommerce through the EasyPay payment page, with signed notifications and status re-checks.

This repository mirrors the free version published on wordpress.org, version 1.0.1.

## Requirements

- WordPress 6.2+ (tested up to 7.1)
- WooCommerce 6.0+ (tested up to 10.7)
- PHP 7.4+

## Install

Install from the WordPress plugin directory (Plugins → Add New → search for the plugin name), or download this repository and upload it to `wp-content/plugins/catcode-card-payments-with-easypay-for-woocommerce/`.
